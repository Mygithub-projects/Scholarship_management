# PROJECT KNOWLEDGE BASE
# AGENTIC AI-POWERED SCHOLARSHIP MATCHING SYSTEM

Version: 1.0
Project Type: PRESTIJ (Agentic AI for Educationists)
Project Category: Resource Optimization, Talent & Workforce Planning
Target Platform: Google AI Studio (Gemini)

## EXECUTIVE SUMMARY

The Agentic AI-Powered Scholarship Matching System is an educational technology prototype designed to assist Malaysian students in identifying scholarship opportunities that best match their academic performance (SPM), co-curricular achievement (PAJSK), psychometric profile, student aspirations and parent socioeconomic background (B40/M40/T20).

## DATASETS

1. Student Master Data
2. SPM Results Dataset
3. PAJSK Dataset
4. Psychometric Dataset
5. Student Aspiration Dataset
6. Parent Background Dataset
7. Scholarship Database

## SIX AI AGENTS

1. Academic Profiling Agent
2. PAJSK Analysis Agent
3. Psychometric & Aspiration Agent
4. Scholarship Matching Agent
5. Recommendation & Reasoning Agent
6. Notification Agent

## SYSTEM WORKFLOW
